# MotionCuesPhone (iOS)

This folder contains the iOS app source that streams CoreMotion data over UDP.

## Open the project
- Open `MotionCuesPhone.xcodeproj`.
  - If you need to regenerate it: run `xcodegen generate` in the `iOS/` directory (uses `Project.yml`).

## Run
- Put your Mac IP address into the app.
- Tap **Start Streaming**.
- On macOS, select `Motion Source: iPhone` in settings.
